# Spotify-Siri-Connection

A collection of AppleScripts and macOS Shortcuts designed to bridge Apple Siri and Spotify, allowing full hands-free voice control over playback, track selection, and playback modes on macOS.

---

## Features

- **Play Specific Tracks**: Search and immediately play requested tracks on Spotify via Siri or Shortcuts.
- **Track Controls**: Easily skip to the next track, return to the previous track, or restart the current track.
- **Playback Modes**: Toggle shuffle and repeat modes effortlessly.

---

## Included Shortcuts & Scripts

| Script / Action | Description |
| :--- | :--- |
| **`Play on Spotify`** | Accepts text/voice input to search and play a specific song directly. |
| **`Next Song`** | Skips to the next track in the queue. |
| **`Previous Song`** | Reverts to the previous track. |
| **`Restart this song`** | Restarts the currently playing track from the beginning. |
| **`Repeat this song`** | Toggles repeat mode for the current track. |
| **`Shuffle Spotify`** | Toggles shuffle mode on or off. |
